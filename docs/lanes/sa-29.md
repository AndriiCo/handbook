## Goal
A hackathon judge clones the repo and runs one command, `cargo xtask
judge`, and within ~10 minutes has a working local copy: the public site
on http://127.0.0.1:18318/apostille with the three hero dossiers (vietnam,
usa-wa-sos, hcch) showing accepted, cited facts, plans and offices; the
admin console on http://127.0.0.1:18319 with a one-time local staff
sign-in link printed in the terminal; and the order flow in local test
mode. No keys needed (recorded Meta responses replay); `--live` uses the
judge's own `META_API_KEY`.

## Steps, in order (estimate; train)
1. **J1** (3h; T1): prerequisite doctor (rustc/cargo version from
   `rust-toolchain.toml`, Node + npm versions from `web/package.json`
   engines, free ports 18318/18319, disk ≥ 6 GB, macOS/Linux) with one
   exact fix command per failure; `judge` = fresh boot via `up`; print a
   short summary (URLs, what to try, how to stop, how to reset).
2. **J2** (4h; T2): seeded content without keys: replay recorded Meta
   responses (drafts, plans, offices from SA-22/SA-23 fixtures once they
   land; today's draft recordings first) and accept them through the real
   accept path (audit rows, no direct DB writes), so dossiers render with
   plans and offices; a one-time local staff sign-in link (loopback only,
   short-lived, refused on any non-loopback bind) instead of mTLS +
   passkey; `judge --check` boots, probes /healthz, the hero dossiers,
   the admin version and exits 0.
3. **J3** (3h; T3): local commerce test mode: request from SA-24/SA-25 a
   loopback-only `orders.local_test` seam (no Stripe or carrier calls;
   simulated paid + sample label PDFs clearly marked TEST) so a judge can
   run the whole order → cabinet flow; refused in any non-loopback boot.
4. **J4** (2h; cuttable): `docker compose -f compose.judge.yaml up` for
   judges without Rust (multi-stage build, same seeds).

## Proof specific to this lane

not your worktree), `cargo xtask judge --check` passes from zero and the
full run serves the hero dossiers; time it and report minutes; run it
once on plant too (Linux, home directory only, ports 18080-18999, never
18318/18319: add a `--port-base` flag). `docs/judges.md` lists exactly
what the judge sees and does in 5 minutes.
