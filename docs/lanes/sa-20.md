# SA-20 "translate" — lane status

Owner: lane SA-20. Branch: `sub/sa-20` (from `origin/main`).

## What this wave delivers

- `fact_translation` table (`CREATE TABLE IF NOT EXISTS` only; no
  `SCHEMA_VERSION` touch) + `crates/web/src/translate.rs`: migration,
  deterministic number/fee/address guard, Muse Spark translation
  (after approval + backfill), rate-limited public read, staff
  translate/backfill/status handlers.
- Translation into `es`/`fr` by `muse-spark-1.3` AFTER staff approval
  (`request_after_accept` queues pending rows; `translate_one` renders
  one row; `backfill_accepted` covers already-accepted facts).
- Guard: digits, currency amounts, PO boxes and street addresses are
  never translated — verified by re-extraction (`guard_ok`); failing
  rows store `guard_ok = 0` and never serve publicly.
- Public dossier `?lang=es|fr` chip + "machine translation ·
  see original" chip (`TranslationChip.svelte`), static es/fr chrome
  catalogs (`public-ui/translate.js`).
- `/review` Translations tab (queue + backfill + per-fact render).
- Shots: `/authority/vietnam?lang=es` + `?lang=fr` routes.
- Meta shapes per `docs/meta-api-shapes.md` + `.agents/meta-api-findings.md`
  (chat completions, `developer`+`user`, `response_format.json_schema`,
  no `temperature` (F1), `reasoning_effort`, `prompt_cache_key`,
  refusal/truncation checks (F10/F11), short error phrases, redacted
  `Debug`). Non-streaming: one fact is a few hundred tokens.
