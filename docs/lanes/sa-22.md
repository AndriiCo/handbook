per-attempt telemetry, `RenderPlanV1` composed by Spark and gated by
deterministic validators plus a Wonder entailment pass, the public
`/plan` read, the Compile run, and the eval modes that prove the gates
catch planted faults.

## Steps, in order (estimate; train)
1. **M1** (3h; T1): `model_call` table (id, at, model, pipeline, run_id,
   attempt, latency_ms, ttft_ms, input/output/cached/reasoning tokens,
   outcome, http_status) + `telemetry::record()` + daily cap from
   `meta.daily_call_cap`; `chat_json(model, developer_prefix,
   prompt_cache_key, user, json_schema, reasoning_effort, pipeline,
   run_id)` returning the parsed value + usage, refusal/length checks,
   one row per HTTP attempt; route the existing draft path through it
   (or record from it) so the trace console gets latency; admin
   `GET /apostille/api/v1/admin/model-calls` (seed `admin-model-calls.json`).
2. **M2** (10h; T2): `page_plan` table (id, authority_slug, version,
   status proposed/accepted/rejected/superseded, plan_json, validator_json,
   run_id, created_at, decided_at, decided_by_role); Spark compose with a
   strict json_schema whose `fact_id` enum is the accepted ids;
   `validate_plan` (ids accepted + same authority; block kind ↔ topics;
   every number, amount, PO box, street number and time appears in a cited
   statement — port `translate.rs` `protected_spans`/`guard_ok`; hours
   guard; no URLs/HTML/banned words; length caps) then a Wonder entailment
   pass that drops unsupported blocks; admin compose/list/accept/reject
   (accept publishes `plan_accepted` via `ws_bus::publish_authority_event`,
   supersedes the previous accepted version, audit row); public
   `GET /api/v1/authorities/{slug}/plan` (always 200, model-free,
   rate-limited, re-filters blocks against current accepted facts, reads
   offices/forms/checks through the seams, provenance with run tokens and
   latency, "Staff reviewer" only); `xtask eval --plans` with planted
   faults (foreign id, invented fee, invented PO box, URL, bad hour) and a
   catch-rate report.
3. **M6** (6h; T3, cuttable): Compile run (`compile_run` table; discover →
   capture → extract → cross-check → offices → compose over `run:{id}`
   with ids from `DraftRuns::reserve_id`; `compile.daily_runs` cap; Spark
   `LinkTriage` over a candidate-id enum on official hosts, robots + SSRF
   guard + 1 req/s per host; calls SA-23's extract/cross-check/offices
   entry points, which it exposes as plain fns — request them).
