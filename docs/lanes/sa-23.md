## Goal
Ground every fact harder and structure what a visitor needs: readable
HTML and PDF text layers, staff document upload for bot-blocked sites,
Wonder cross-checks, structured offices with hours, and official PDF forms
mapped by Spark and filled server-side.

## Steps, in order (estimate; train)
1. **E1** (6h; T1/T2): readable HTML text (boilerplate stripped, byte
   offsets stable into the `text/<id>.txt` sidecar), lopdf text layer +
   AcroForm field list for PDFs, staff `POST
   /apostille/api/v1/admin/captures/upload` (PDF → `capture(kind=file,
   trust=staff_verified)` with a sidecar; for sos.wa.gov's 403).
2. **O1** (5h; T2): `office_record` table; Spark `OfficeSetV1` from
   accepted address/hours/walkin/appointment/po_box/mailing facts;
   `address_ok`, `hours_ok` (am/pm, ranges, days), PO box forced from cited
   text, tz only when quoted or staff-confirmed; admin list/accept/reject
   (accept publishes `offices_accepted`); fill `offices::accepted_for_slug`
   (seed `plan.json` `offices[]`).
3. **M3** (4h; T2): `fact_check` table; Wonder `FactChecksV1` over the whole
   sidecar (quote must be a sidecar substring, else `not_found`); admin
   list/run; fill `factcheck::checks_for_slug`; the verdict is recorded
   before accept so the public chip is honest.
4. **F1** (6h; T3): `form_map` table; Spark `FormMapV1` (AcroForm names
   from an enum, label must be in its cited span); accept INSERTs a
   `form_template` (status active); customer `POST
   /api/v1/p2/forms/{id}/fill` → fill-and-flatten the official PDF with
   lopdf (prefill via `compute_prefill`, p2.rs:464, which withholds
   conflicts) → stored fill + PDF route; fill `forms_map::accepted_for_slug`.
5. **M4** (3h; T3, eval-gated): topic-group extract passes (office,
   money/time, prepare/mail, routing); long text to muse-wonder-1.0.
6. **F2** (3h; cuttable): clean-room redraw for flat PDFs.
